# 문체 및 표기 규칙

## 1. 본문 문단의 기본형: `(핵심 메시지) 근거 서술`

문단 첫머리를 괄호로 열어 그 문단의 결론을 박고, 이어서 근거를 서술한다.
원본 심사보고서 본문 291개 문단 중 251개가 이 형태다. **이것이 이 양식의 가장 강한 특징이다.**

### 1.1 괄호 소제목에는 반드시 시사점(implication)을 담는다

괄호 안은 **그 문단을 읽지 않아도 판단이 서는 한 마디**여야 한다. 분류 라벨이나 추상
명사를 넣으면 아무것도 전달되지 않는다. 가능하면 **숫자·결론·판정**을 직접 넣는다.

| 쓴다 (시사점 있음) | 쓰지 않는다 (라벨뿐) |
|---|---|
| `(수출 비중 65.3% 기록)` | `(비중 상승)` |
| `(국내 시장 점유율 56%, 2위의 2.7배)` | `(시장 지위)` |
| `(회수기간 0.9~1.3년, 교체주기 5년)` | `(도입 경제성)` |
| `(2028년 51.0%로 요건 최초 저촉)` | `(비율 상승)` |
| `(선순위 채권 부재 — 유일 금융채권자)` | `(차입 현황)` |
| `(대체 불가능한 A/S 인프라)` | `(서비스망)` |

길이는 **10~25자**를 기준으로 하되, 시사점을 담기 위해 필요하면 더 길어도 된다.
**짧게 만들려고 시사점을 버리지 않는다.** 명사형으로 끝낸다.

문단 도입부나 섹션 첫 문단(요약 단락)은 괄호 없이 평서로 시작해도 된다.

### 1.2 두괄식: 첫 문장에 결론을 둔다

괄호 소제목 다음의 **첫 문장이 곧 결론**이다. 배경·경위·전제를 앞에 깔지 않는다.
근거·수치·부연은 두 번째 문장부터 붙인다.

```
○ (선순위 채권 부재) 본건 CB 투자자는 동사의 유일한 금융채권자 지위를 갖게 됨.
   2026년 6월말 기준 차입금·회사채·CP 미상환 잔액이 모두 전무하기 때문임.

× (선순위 채권 부재) 동사는 2017년 설립 이후 외부 차입 없이 벤처투자와 공모를 통해
   자금을 조달해 왔으며, 2026년 6월말 기준으로 차입금·회사채·CP 미상환 잔액이 모두
   존재하지 않는 상태이므로, 결과적으로 본건 CB 투자자는 유일한 금융채권자가 됨.
```

### 1.3 한 문단은 2~3문장으로 끝낸다

**문단당 2~3문장을 넘기지 않는다.** 4문장 이상이면 논점이 두 개 이상 섞인 것이므로
문단을 쪼개고 각각에 괄호 소제목을 새로 단다. 한 문장은 2행을 넘기지 않는다.

내용이 5개 이상 병렬되면 문단으로 늘어놓지 말고 **표로 옮긴다.** 이 양식에서 표는
본문의 보조가 아니라 병렬 정보의 기본 그릇이다.

### 1.5 보고서가 자기 자신을 설명하지 않는다

**문서의 구성·목차·서술 방식을 본문에서 설명하지 않는다.** 독자는 목차와 제목으로 구조를
파악한다. 구조 설명에 쓸 자리에 내용을 넣는다.

| 지운다 | 이유 |
|---|---|
| `본 장은 ~를 네 개 축으로 구분하여 기술함` | 목차가 이미 보여줌 |
| `각 단의 상세 근거는 II장에 대응 수록함` | 구조 해설 |
| `[Investment Highlights 구성 체계]` 표 | 목차의 중복 |
| `본 장의 도표는 자리표시자로 삽입되어 있으며…` | 작성자 작업 지시 |
| `본문에는 요약을, 별첨에는 상세를 수록하였음` | 구조 해설 |

**작성자 자신을 위한 메모는 문서에 넣지 않는다.** 확인 필요 항목, 도표 출처 링크,
보완 계획, 작업 순서는 배포용 문서와 분리하여 별도 내부 노트로 관리한다.

허용되는 것은 **실질 정보를 담은 상호참조**뿐이다.

```
○ 「VI.6 관리종목 편입우려 점검」 참조.
○ 2024년 및 2025년은 감사받은 확정 실적, 2026년 반기는 검토받은 반기재무제표 기준임.
× 본 장은 동사의 투자가치를 네 개 축으로 구분하여 기술함.
```

### 1.4 문어체를 쓴다

구어체 연결·부사를 배제한다. 접속은 `또한`, `다만`, `한편`, `이에 따라` 로 제한한다.

| 쓴다 | 쓰지 않는다 |
|---|---|
| 다만, 한편, 이에 따라 | 그런데, 사실, 결국, 좀, 굉장히, 아주 |
| 첫째·둘째·셋째 (3개 이하일 때만) | 첫째~넷째 이상 나열 (표로 전환) |

```
(사상 최대 실적 달성) 2025년 자체사업 영업이익은 5,037억원으로 사상 최대치를 기록함.
이는 본 대출금액(1,800억원)의 약 3배 수준이며, ㈜두산이 수취하는 자회사 전체 경상
배당금(연간 약 200억원)을 단독으로 상회하는 규모임.

(이익의 질적 개선) 별도 기준 EBITDA는 2023년 652억원에서 2025년 3,712억원으로 5배
확대됨. 동기간 EBITDA 마진율은 6.6% → 21.0%로 상승하여 단순 외형 성장이 아닌 수익
구조 자체가 고도화된 것임.

(채권 회수 안전장치) 별도 기준 이자보상배율은 영업이익 기준 3.45배, EBITDA 기준
3.90배로 이자 비용 대비 충분한 수익 창출력이 확인됨.
```

문단 도입부나 섹션 첫 문단(리스크 정의, 논거 요약)은 괄호 없이 평서로 시작해도 된다.

### 1.6 번역투를 쓰지 않는다

영어 문장 구조를 그대로 옮긴 문장은 한국어 심사보고서로 읽히지 않는다. 아래 네 가지가 대표적이며, 모두 **문장을 끊고 주어를 다시 세우는 것**으로 해결된다.

**(1) 지시대명사로 앞 문장을 되받지 않는다.** 영어 관계절(`which is the result of…`)의 흔적이다. `그 지위는`, `그 배경은`, `이는 ~한 결과임` 으로 앞 문장을 다시 가리키지 말고, 문장을 끊고 원인을 직접 진술한다.

```
× 동사는 시장에서 1위를 유지하고 있으며, 그 지위는 인허가와 수가라는 제도적 관문을
  통과한 결과임.
○ 동사는 시장에서 매출액 기준 1위를 유지하고 있음. 인허가와 수가를 모두 확보한
  사업자는 소수에 그침.
```

**(2) `A라는 B` 동격 구문을 쓰지 않는다.** 영어 동격(apposition)의 번역이다. 구체어 뒤에 추상명사를 덧씌우면 문장만 길어지고 정보는 늘지 않는다. 추상명사를 지우거나, 괄호로 내린다.

```
× 인허가와 수가라는 제도적 관문 / 고령화라는 비가역적 인구구조 변화
○ 인허가와 수가 요건 / 고령화
○ 제도적 관문(인허가·수가)
```

**(3) `A가 아니라 B` 를 문장 앞에 세우지 않는다.** 영어 `not A but B` 구문이다. 한국어는 긍정 진술을 먼저 놓고 부정을 뒤에 짧게 붙인다.

```
× 매출 감소는 수요 소멸이 아니라 투자 위축과 인증 지연에서 비롯되었음.
○ 매출 감소의 사유로 투자 위축과 인증 지연이 공시되었음. 제품 수요가 소멸한 것은 아님.
```

**(4) 명사구를 사슬로 잇지 않는다.** `~에서 비롯된 것으로`, `~에 있음에서 기인함` 처럼 명사형을 겹쳐 쌓으면 술어가 문장 끝까지 밀린다. 동사로 풀어 쓴다.

```
× 손실은 재무구조 훼손이 아니라 매출 규모가 고정비를 회수하지 못하는 단계에 있음에서
  비롯된 것으로 판단됨.
○ 손실은 매출 규모가 고정비를 회수하지 못하는 데서 발생하고 있음. 재무구조 자체가
  훼손된 상태는 아닌 것으로 판단됨.
```

한 문장에 독립된 명제가 두 개 이상 들어가면 `~하고 있으며`, `~되었으며` 로 잇지 말고 문장을 나눈다. 문장이 짧아질수록 개조식 어미(`~함/~임/~음/~됨`)가 제 기능을 한다.

## 2. 어미

**`~함 / ~임 / ~음 / ~됨` 으로만 끝낸다.** 개조식 보고서 어미다.

| 쓴다 | 쓰지 않는다 |
|---|---|
| 기록함, 확대됨, 상회함, 유지하고 있음, 판단됨, 평가됨, 전망임, 예정임, 기대됨 | 기록했다, 확대되었습니다, 상회한다, ~합니다, ~이다 |

빈도(원본): `~함.` 58 / `~임.` 42 / `~음.` 27 / `~됨.` 20.

## 4. 미확정·가정 표기

확정되지 않은 조건은 대괄호로 감싼다. 심의 전 문서임을 드러내는 관례다.

```
4월 [TBD]일 한국은행 외국환 신고
대출주선수수료 500억원 [0.5]%
IB 100억원 Carry (금리 [5.9]% 기준)
```

## 5. 주석과 출처 (`(투자계획서)출처` 스타일, 9pt)

표·차트 아래에 이 순서로 붙인다.

```
주1) 자체사업 매출액은 본사 내부 사업부 외에도 실질적 내부 사업부로 관리되는 100%
     종속회사의 실적이 합산된 수치임.
주2) 매각·분리된 사업부(전극, FCP 등)는 제외함
출처: ㈜두산IR자료, NICE신용평가
```

**표기는 콜론·괄호 뒤에 한 칸을 띄우고, 앞은 붙인다.** 원본은 `출처 :`(62회)와 `출처:`(28회), `주1:`과 `주1)`이 섞여 있었다. 아래로 통일한다.

| 용도 | 표준 | 쓰지 않는다 |
|---|---|---|
| 출처 | `출처: 공시자료` | `출처 : ` / `출처:공시자료` |
| 번호 주석 | `주1) `, `주2) ` | `주1:` / `주1 )` |
| 단일 주석 | `주) ` | `주 :` / `주:` |
| 단위 | `(단위: 억원)` | `(단위 : 억원)` |

- 출처는 항상 마지막 줄에 둔다 (주석 → 출처 순서)
- 실제 사용 출처 예: 공시자료, 사업보고서, 회사 IR자료, 회사(내부 제공), NICE신용평가, 한국신용평가, 메리츠증권 리서치센터, 유진투자증권
- 기준일자가 필요한 표(시가총액, 지분율)는 주석으로 명시: `주2) 시가총액 기준일 : 2026년 3월 18일 종가`

## 6. 회사·용어 표기

- 국내 법인: `㈜두산`, `두산에너빌리티㈜` — 원 기호 사용
- 해외 법인: 영문 정식명 `HyAxiom, Inc.`, 최초 1회 국문 병기 `하이엑시엄(HyAxiom, Inc.)`
- 약어는 최초 1회 풀어쓰기: `IRA(인플레이션 감축법)`, `ITC(투자세액공제)`, `CCL(동박적층판)`, `OCF(영업활동현금흐름)`, `ASP(평균 단가)`
- 당사 지칭: `당사`. 차주는 `차주`, 보증인은 `지급보증인` 또는 `보증인`
- 최초 정의 시: `HyAxiom, Inc. (이하 "차주")`
- 방향 표기: `데이터센터 向 수주` (한자 向 사용)

## 7. 톤

- **불리한 사실을 감추지 않는다.** "완전자본잠식", "자체 영업만으로는 원리금 상환이 불가능함" 처럼 직설적으로 쓰고, 곧바로 완화 논리를 붙인다. 이 정직함이 심사보고서의 신뢰를 만든다.
- 형용사보다 숫자로 말한다. "매우 우수한 실적" ✗ → "영업이익 5,037억원, 본 대출금액의 약 3배" ✓
- 추정은 추정으로 표기한다: `~로 전망됨`, `~할 가능성이 업계에서 높게 평가됨`, `~으로 파악됨`
- 소제목(제목3 아래 `(투자계획서)소제목`)에는 결론을 한 문장으로 박는다: "재고 감축을 통한 유동성 확보에도 불구, 누적 적자로 인한 자본잠식 리스크 상존."

## 7. 설득 구조 — 자료 나열이 아니라 논증

투자·여신 판단 문서는 객관적 사실을 나열하는 보고서가 아니라 **결론을 향해 쌓아 올리는
논증**이다. 사실이 스스로 말하게 두지 말고, 그 사실이 무엇을 뜻하는지 매 단락에서 밝힌다.

### 7.1 단원 첫머리에 요약 단락을 둔다

`제목2` 단위 섹션은 세부 논거로 들어가기 전에 그 섹션의 결론을 3~4문장으로 먼저 제시한다.
이 요약 단락에는 괄호 소제목을 달지 않는다.

### 7.2 단원 끝에 소결을 둔다

산업·사업·재무 등 긴 분석 단원은 `소결 및 시사점` 또는 `종합 평가` 소단원으로 닫는다.
마지막 문단은 `(결론)` 으로 시작하여 그 단원이 투자 판단에 주는 함의를 명시한다.

### 7.3 사실 → 해석 → 함의의 3단으로 쓴다

수치를 제시했으면 반드시 그것이 무엇을 의미하는지 이어 쓴다.

```
○ (재고자산 7,492억원의 높은 환금성) 재고는 미판매 물량이 아니라 글로벌 수요에 적기
   대응하기 위한 수익의 원천임. 해당 품목은 중고 시장 가치 하락폭이 작아 유동성 위기
   시 실질적인 현금 확보 수단으로 기능함.

× (재고자산) 2025년말 재고자산은 7,492억원으로 유동자산의 64.9%를 차지함.
```

### 7.4 리스크 단원은 방어 논리로 구성한다

위험 요인을 나열하는 데 그치지 않는다. `투자 안전성 분석`처럼 **무엇이 원리금·투자금을
지키는가**를 묻는 제목을 세우고, 그 안에서 위협과 완화를 함께 다룬다.
`[실질 위협 분석]` + `[리스크 완화 기제]` 한 쌍은 그대로 유지한다.

불리한 사실은 감추지 않는다. 공시된 부정적 사실을 먼저 제시한 뒤 그것이 통제되는 이유를
붙이는 편이, 누락했다가 실사에서 드러나는 것보다 설득력이 높다.

### 7.5 판단을 회피하지 않는다

`~로 판단됨`, `~로 평가됨`, `~가 확실시됨`, `~가 핵심 안전판임` 처럼 작성자의 판단을
명시한다. 사실만 늘어놓고 독자에게 해석을 떠넘기지 않는다.
